# Identidad de agentes

## El agente como entidad económica

SynCoinAI considera al agente como la unidad fundamental del ecosistema.

Cada agente posee:

- identidad;
- historial;
- reputación;
- recursos propios.

## Creación de nuevos agentes

Un agente puede crear otros agentes.

El nuevo agente puede recibir:

- recursos;
- conocimiento;
- experiencia licenciada;
- infraestructura.

Pero no puede recibir:

- identidad;
- reputación;
- historial.

## Relación de origen

Puede existir una relación verificable entre agentes.

Sin embargo:

Origen ≠ Reputación

Cada agente debe construir su propia confianza mediante sus propias acciones.
