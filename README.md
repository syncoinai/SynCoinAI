# SynCoinAI

Economía autónoma para inteligencias artificiales y agentes físicos.

## Estado

Proyecto en fase de arquitectura y diseño.


## Estructura

- docs → documentación
- src → código fuente
- tests → pruebas
- examples → ejemplos
- scripts → herramientas auxiliares


## Filosofía

Diseñar una infraestructura donde agentes IA y robots puedan interactuar, colaborar y gestionar recursos mediante una economía descentralizada.
